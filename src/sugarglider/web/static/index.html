                Speech language and service
                Advanced settings

                Asphalt, exact retracing, technical difficulty and current access cannot yet be verified. Elevation is measured after routing; a climbing target is not guaranteed.

                Start and End

                Start and End are optional here: describe them by text or speech, or choose them on the map. Suggested locations are reviewed before routing. A loop returns to its Start.

                What is sent and saved?

                When you Generate, your description, chosen Start/End, required points and up to 24 nearby mapped places (names, IDs and coordinates) are sent to OpenAI using your connected ChatGPT account. Research is online. Route calculations, complete regional packs and GPX stay on this device. Your ChatGPT plan limits apply. If the extra request is enabled, measured route summaries and reached mapped place names/OSM IDs may be sent to research stories or improve suggestions. The latest completed adventure, including selected places and stories, is kept locally for restart recovery; you can forget it or clear saved offline data.

                Confirm required places

                Search sends only this place name to IGN Géoplateforme. It does not change your region or use online routing.

                Import itinerary

                This importer reads itinerary JSON locally. Paste JSON generated elsewhere, or choose a JSON file. Plan with AI connects to ChatGPT separately in the Android app.

                One version 1 JSON object, optionally in a JSON code fence. Maximum 64 KiB.

                Build a prompt locally, then inspect or edit it. Copying may include your chosen Start coordinates. Nothing is sent automatically.
